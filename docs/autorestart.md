# إعادة التشغيل التلقائي (Auto-restart) — مبني ومُختبر

## الهدف
البوت يعود للعمل وحده بعد أي توقف/انهيار/إعادة تشغيل، دون تدخل يدوي.

## المكوّنات
| الملف | الوظيفة |
|---|---|
| `deploy/guard.py` | حارس يستمر بالمراقبة كل **45 ثانية**؛ إن لم يجد عملية `python -m app.main` يبدأها فورًا ويكتب السجل |
| `deploy/guard_start.bat` | لتشغيل الحارس في الخلفية بلا نافذة |
| `deploy/install_autostart.cmd` | يضع الحارس في مجلد بدء ويندوز (بلا صلاحيات أدمن) |
| `logs/guard.log` | سجل كل فحص/إعادة تشغيل/خطأ |
| `logs/bot.pid` | معرّف العملية الحالية |

## الاختبار الفعلي (مُنفَّذ)
1. شغّلت الحارس (PID 4956) وبدأ السجل: `guard started — interval=45s`.
2. **أوقفت البوت قسريًا** (`taskkill /F`) — كان PID 3848.
3. خلال **~46 ثانية** سجّل الحارس: `bot DOWN — restarting` ثم `STARTED pid=16580`.
4. تأكيد أن النسخة الجديدة تعمل: أرسلت أمرين من حساب تليجرام حقيقي:
   - `/start` ⇒ ردّ: «🕌 بوت القرآن الموحّد …» خلال **1.3s**
   - `/ayah 112:1` ⇒ ردّ بنص الآية خلال **1.3s**
5. زمن العودة الكلي من الإيقاف إلى ردّ فعلي: **أقل من دقيقة**.

## التثبيت لإعادة التشغيل بعد إعادة تشغيل الجهاز
```powershell

```
يضيف اختصارًا في مجلد بدء ويندوز (يعمل عند تسجيل الدخول، بلا أدمن). أو يدويًا:
```powershell

```
