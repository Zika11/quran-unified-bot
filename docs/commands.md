# قائمة الأوامر النهائية (البوت الموحّد)

## القرآن
| الأمر | الوظيفة |
|---|---|
| `/surah <رقم\|اسم>` | نص السورة كاملًا + زر استماع (مثال: `/surah 18` أو `/surah الكهف`) |
| `/ayah <سورة:آية>` | آية + أزرار: استماع · تفسير ميسر · مقارنة قرّاء · فيديو |
| `/tafsir <سورة:آية>` | التفسير الميسر (AlQuran.Cloud) |
| `/search <كلمة>` | بحث في القرآن كله |
| `/random` | آية عشوائية |
| `@البوت <كلمة>` | بحث مضمّن (Inline) داخل أي محادثة |

## التلاوات والإذاعات
| الأمر | الوظيفة |
|---|---|
| `/reciters` | اختيار القارئ (8 قرّاء) |
| `/play <رقم>` | تلاوة السورة كاملة بالقارئ المختار |
| `/radios` | الإذاعات المباشرة من MP3Quran |

## قرارات تصميم الأوامر
- لا أوامر عربية (تليجرام يقبل `a-z0-9_` فقط) — العربية متاحة عبر **الأزرار** والنصوص الحرة.
- لا تعارض أسماء: كل أمر له وظيفة واحدة.
- `/kh*` اختصارات الختمة، `/hz*` اختصارات الحفظ.

## قائمة الأوامر الحيّة على تليجرام (عملية مُنفَّذة)
تم ضبط **25 أمرًا** فعليًا على البوت عبر `setMyCommands` والتحقق منها بـ `getMyCommands` (سكربت `tools/set_commands.py`) ⇒ تظهر الآن في قائمة أوامر تليجرام تلقائيًا للمستخدم. التفاصيل: `tools/telegram_commands.json`.
